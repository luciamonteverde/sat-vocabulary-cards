Visibility mechanism probe

Three probes for the proposed SAT card structure. Each asks one question with an obvious answer — what matters is what happens to the TEACHING CONTENT block, not the question. Read the result line after each.

Probe A should hide content. Probe B should reveal content. Probe C should do the whole cycle in one item and is the one we do not already know the answer to.

Probe A — can we HIDE taught content?

Answer correctly, then check whether the block above the question vanished.

Probe B — can we REVEAL hidden content?

Nothing should sit above the question until you answer correctly.

Probe C — the full cycle in one item

Three stages: study, then answer with the content hidden, then see it again.
